NAME

ndns — complete NextDNS account CLI

Complete NextDNS account CLI. Full official-API coverage. Deno + Bun single-file TS.

Docs + command reference: https://ndns.oriz.in

Command reference Install
nextdns@cli ~ $

SYNOPSIS

whoamiprofiledenylistallowlistblocklistnativesecurityparentalprivacysettingsanalyticslogsconfig

Commands

ndns whoami

Verify API key + list profiles

ndns profile <list|show|create|update|delete>

Profile CRUD

ndns denylist <list|add|remove|toggle-active|bulk-add|bulk-remove|export|import>

Block domains

ndns allowlist <...>

Same shape as denylist

ndns blocklist <list-available|list|subscribe|unsubscribe>

Curated blocklists

ndns native <list|add|remove>

Native tracker feeds (Apple/Google/etc.)

ndns security <show|set|tld>

Threat protection settings

ndns parental <show|safe-search|youtube-restricted|block-bypass|services|categories>

Parental control

ndns privacy <show|set>

Privacy toggles

ndns settings <show|logs|blockpage|performance>

Profile settings

ndns analytics <resource> <profile>

11 endpoints, time-series via --series

ndns logs <list|stream|download|clear>

Query logs, SSE stream

ndns config <export|import>

Full profile backup / restore

Flags

FlagMeaning
--output=<table|json|csv>Output format (default: table for lists, json for objects)
--from=<date>ISO 8601, unix seconds, unix ms, or relative (-6h, -1d, -7d)
--to=<date>Same as --from
--limit=<n>1-500 for analytics, 10-1000 for logs
--device=<id>Filter by device ID (or __UNIDENTIFIED__)
--search=<text>Log/analytics search
--seriesAnalytics time-series mode
--interval=<1d|1h|30m>Series bucket size
--timezone=<IANA>e.g. America/New_York
